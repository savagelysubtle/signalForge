## Mission

Rebuild the SignalForge frontend from the ground up. The current UI is functional but generic. The goal is a **distinctive, polished, professional trading dashboard** that feels like it was designed by a human with strong opinions — not generated by AI.

### How to Apply This

Every frontend component, view, and style change on this branch must pass through this lens:

1. **Before writing any component**, consider: would a senior designer approve this, or does it look like every other AI-generated dashboard?
2. **Typography must be intentional.** See font pairing below — no Inter, no Roboto, no Space Grotesk.
3. **Color palette is the Urban Finance palette below.** No deviations without discussion.
4. **Motion must be purposeful.** Staggered reveals on page load, smooth transitions between states, micro-interactions on key actions. CSS animations first, Motion library for complex orchestration.
5. **Background is a real photograph** (`bg-urban-finance.jpg`) — a desaturated metropolitan skyline. It is persistent across all views via the `.bg-urban-finance` CSS class on a fixed layer in `MainLayout`. Never replace it with an SVG or CSS-only background.
6. **Chart images must be large.** Chart-Img outputs displayed at a size clearly readable on a 1920x1080 desktop monitor — minimum 800px wide, preferably filling the available content area.
7. **Layouts must feel like a real product.** Think Bloomberg Terminal density, Wealthsimple editorial polish, TradingView chart prominence. Not a generic admin dashboard.

### Typography

**Font pairing: "Terminal Precision"**

- **Display / Headings / Tickers / Numbers:** `JetBrains Mono` — monospaced with ligatures. Evokes terminal aesthetics. Loaded via `@fontsource-variable/jetbrains-mono`.
- **Body / Labels / UI text:** `Satoshi` — modern geometric sans from Fontshare. Loaded via `<link>` in `index.html`.
- **Fallback stack:** `'JetBrains Mono Variable', 'JetBrains Mono', monospace` / `'Satoshi', system-ui, sans-serif`

**Rules:**
- All ticker symbols, prices, percentages, and numerical data use JetBrains Mono
- All body text, labels, buttons, and navigation use Satoshi
- Font sizes follow a strict scale: 11px (xs), 13px (sm), 15px (base), 18px (lg), 24px (xl), 32px (2xl), 48px (3xl)

### Background System

The background is a **real photograph** (`src/assets/bg-urban-finance.jpg`) of a desaturated metropolitan skyline (dark steel/glass skyscrapers). It is applied as a persistent fixed layer across all views.

**Architecture:**
- `MainLayout` renders the background as a `fixed` div with class `bg-urban-finance` behind the main content
- `LoginPage` (outside MainLayout) renders its own `bg-urban-finance` layer
- `ProtectedRoute` loading state also includes the background layer
- The CSS class applies `filter: brightness(0.35) contrast(1.3) saturate(0.7)` to darken the image and keep it moody

**Rules:**
- The background must be visible through all views — avoid opaque `bg-bg-void` containers that fully cover it
- Use `bg-bg-asphalt/80 backdrop-blur-md` for chrome elements (TopBar, sidebars) so the background subtly shows through
- Use `bg-bg-concrete` for input fields, cards, and interactive elements (provides contrast for readability)
- Grid pattern (`bg-grid-fade`) and noise texture (`bg-noise`) are layered on top of the photo for additional depth
- Never replace the photo with an SVG recreation or CSS-only background

### Chart Display Rules

Chart-Img images are the centerpiece of the analysis. They must be displayed prominently:

- **Minimum width:** 800px or 100% of content area (whichever is larger)
- **Aspect ratio:** Maintain native Chart-Img aspect ratio (typically 16:9 or similar)
- **Container:** Full-bleed within their panel — no excessive padding shrinking the image
- **Lightbox:** Click to expand to near-fullscreen with backdrop blur
- **Multiple timeframes:** Displayed as a tabbed or carousel interface, not thumbnails
- **Annotated charts:** Shown side-by-side with base charts when screen width allows (>1440px), stacked below on smaller screens

### Navigation
- **TopBar** (`components/layout/TopBar.tsx`) — horizontal top bar with logo left, centered nav pill, user/logout right
- Nav items: Dashboard (`/`), History, Strategies, Insights, Settings — centered via `absolute left-1/2 -translate-x-1/2`
- TopBar uses `bg-bg-asphalt/80 backdrop-blur-md` for semi-transparency
- On results screen (`?run=` param present), nav is hidden and a "Back to Search" button appears

## Technical Constraints

These carry over from the root CLAUDE.md but are repeated for clarity:

- **React 19** + **TypeScript 5.9** + **Tailwind v4** + **Vite 8**
- **Bun** as package manager (`bun add`, `bun run dev`)
- **Lucide React** for icons
- **React Router v7** for routing
- **Supabase JS SDK** for auth
- **Motion** (`motion/react`) for animations
- **clsx** for conditional class names
- All TypeScript interfaces in `types/index.ts` must mirror Python Pydantic models
- The frontend **never** calls LLM APIs directly — everything goes through the FastAPI backend
- Dark theme only (for now)

### Allowed New Dependencies

These may be added if they serve the aesthetics directive:

- **Google Fonts** — via `@fontsource/*` packages or `<link>` tags
- **CSS libraries** for textures/patterns if lightweight
- Other UI primitives (headless UI, Radix) if they enable better UX without bloat

### Forbidden

- No component libraries that impose their own design system (MUI, Chakra, Ant Design, shadcn/ui)
- No CSS-in-JS (styled-components, emotion) — Tailwind only
- No state management libraries (Redux, Zustand, Jotai) unless complexity demands it — prefer React context + hooks
